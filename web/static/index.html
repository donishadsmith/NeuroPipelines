WhereAmI MNI Lookup

  • Text output originates from AFNI's whereami using the FS.afni.MNI2009c_asym and Brodmann_Pijn_AFNI atlases.
  • The "Cohort" field doesn't change the output, it is literally used to determine the T1w MNI template (adult vs pediatric) to draw the spheres on.
  • The "Transform Method" field is only used when the "Coordinate Space" is set to "Talairach".
  • If the coordinate is in Talairach space then use the Lancaster method unless the paper is pre-2010 or specifically states that the Brett transform was used.
  • The {TLRC} line in the text output is AFNI's own conversion of the MNI coordinate, so it will not match a Talairach coordinate entered here.
